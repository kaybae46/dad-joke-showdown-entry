## The joke

> I told my suitcase we weren't going on vacation this year. Now I'm dealing with emotional baggage.

## How it works

`main.ts` writes the single dad joke (98 characters) to `/output/entry.txt`, validates it against the gate (UTF-8 text, 1–200 characters, not whitespace-only), and reads it back to confirm the file on disk holds exactly the validated joke.

Run it with:

```sh
node main.ts
```
